# LLM Mention Tracker — First Credentialed Run, 2026-09-06

**AEO Playbook Play 6.** This is the first real, credentialed execution of the
baseline described in `LLM_MENTIONS_2026-08-24.md` — 10 brand-free buyer
questions × 3 runs = **30 real Claude answers**, via DataForSEO's
`ai_optimization/claude/llm_responses/live` endpoint (web-search-enabled Claude,
matching how a real prospective buyer would ask). Brand matching used the exact
existing tracker logic in `lib/growth/llm-mention-tracker.ts`
(`BRANDS`/`aliasRegExp`/`countBrandMentions`) — no ad hoc counting.

Scope note: the original template called for 5 runs/question (50 answers
total); this run used 3 runs/question (30 answers) per explicit scope
decision this session. Re-running at 5/question later will extend, not
replace, this baseline.

## Bottom line

Lovable (30%) and Bolt (27%) are the real, dominant answer-engine incumbents
right now; Replit trails at 13%. Builder/AINative and Polsia are statistically
identical at 0/30 — real proof that Builder's AX investment (llms.txt,
agents.txt, structured data — see `SEO_PAID_BRIEF_2026-08-24.md` §5) has not
yet translated into LLM answer-engine visibility, because visibility here is
driven by what LLMs already know and cite about a brand (training data +
retrieved web mentions), not by a target site's own crawlability. AX makes
Builder *ready* to be cited; it does not by itself cause a citation. Closing
this gap requires the off-site AEO plays discussed alongside this tracker
(Brave/other-engine presence, brand-shortlist inclusion, earned off-site
mentions, review-site submissions — Trustpilot/G2/Product Hunt) — the same
category of off-site presence Lovable and Bolt already have and Builder does
not. These plays are not yet captured in a dedicated doc in this folder; that
is the concrete next-doc gap this baseline surfaces.
