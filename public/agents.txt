# agents.txt — AINative Builder
# Agent-facing manifest: how an autonomous agent can use AINative Builder to
# build and run a company programmatically. Builder is agent-native by design.

Name: AINative Builder
Purpose: Build a real, running product or an operating AI-native company from a plain-language idea, then run it 24/7 on real AINative primitives.
Base-URL: https://builder.ainative.studio
Docs: https://docs.ainative.studio
Live-proof: https://ainative.studio/api/v1/public/platform/intelligence

# --- Agent capabilities (call these directly) ---

Capability: generate-app
  Method: POST
  Path: /api/chat-ws
  Body: { "message": "<the idea>" }
  Returns: SSE stream; the `init` event gives a chatId. The running app is served
           at /api/preview/{chatId} and shareable at /preview/{chatId} (durable).

Capability: generate-artifact
  Method: POST
  Path: /api/build/artifact
  Body: { "view": "brief|prd|comp|dataModel|memoryPolicy|agentDef|apiSpec|backlog|thesis|wedge|businessModel|positioning|landing|plan30", "idea": "<idea>", "track": "app|company", "companyName": "<optional>", "prior": {} }
  Returns: { "view", "content": <structured JSON for that artifact>, "provider", "model", "tier" }
  Notes: content is idea-specific, generated by Claude (Bedrock), tiered by plan.

Capability: ask-cody
  Method: POST
  Path: /api/build/ask
  Body: { "question": "<question about the company>", "idea": "<idea>", "companyName": "<name>", "track": "app|company" }
  Returns: { "answer", "provider", "model" }

Capability: business-systems
  Method: GET
  Path: /api/build/systems?companyId=<id>
  Returns: { "systems": [ { "key", "name", "primitive", "url", "stat", "count" } ], "zeroState" }
  Notes: real per-company state (ZeroPipeline/ZeroInvoice/ServiceOS/ZeroVoice), honest zero-state for a new company.

Capability: enroll-nightly-loop
  Method: POST
  Path: /api/build/enroll
  Body: { "companyId", "companyName", "track", "goal" }
  Effect: enrolls the company in the nightly autonomous loop (Cody runs the highest-leverage task each night).
